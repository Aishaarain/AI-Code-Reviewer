WHAT THE METRICS MEAN
----------------------
Accuracy:        Overall correctness (want: >80%)
Precision:       When agent flags something, is it real? (want: >70%)
Recall:          Does it catch real issues? (want: >70%)
F1-Score:        Balance between precision and recall
Hallucination:   False positive rate (want: <30%)


IMPROVE AGENTS
--------------

                 reviewer\prompts\security.md
                 reviewer\prompts\style.md

2. Make agents more conservative (reduce false positives)

3. Add examples of what TO flag and what NOT to flag

4. Re-run tests after changes


ADD MORE TEST CASES
-------------------

Add to TEST_CASES list with:
  - id: unique number
  - description: what you're testing
  - diff: git diff of code changes
  - expected: what agents should find


TROUBLESHOOTING
---------------
"No module named pytest"
  → .venv\Scripts\python.exe -m pip install pytest

"Unicode error"
  → Use run_tests.py (not evaluate_agents.py directly)

"Rate limit error"
  → Wait 10 seconds and try again
